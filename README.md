## 💬 4. Interação com o Chat (Perguntas, Respostas e Citações)
Abaixo estão exemplos de perguntas feitas ao assistente e como ele fundamentou suas respostas:

* **Pergunta 1:** *"Qual é a principal diferença prática entre usar `interface` e `type` no TypeScript?"*
  * **Resposta do Notebook:** O assistente explicou que, embora ambos sejam usados para definir a forma de um objeto, `interface` é ideal para declaração de objetos e suporta *declaration merging* (fusão de declarações), enquanto `type` é mais versátil para criar uniões (`union types`), primitivos e tuplas.
  * **Fonte Citada:** *Total TypeScript Ebook (Capítulo de Fundamentos de Tipagem)*.

* **Pergunta 2:** *"Como o TypeScript lida com valores opcionais em propriedades de objetos?"*
  * **Resposta do Notebook:** Explicou o uso do operador `?` e detalhou como o tipo resultante passa a aceitar o valor `undefined` implicitamente, recomendando o uso de *strictNullChecks*.
  * **Fonte Citada:** *TypeScript Official Handbook*.
